# Suffa Education School — Website

A premium, fully responsive multi-page frontend website for **Suffa Education School**, built to reflect the school's brand identity of academic excellence, character, trust, and modern education.

The design follows an editorial, photography-led visual system — asymmetric layouts, generous whitespace, and a refined navy-and-gold palette — rather than a generic template look.

---

## 🎨 Design Overview

- **Color Palette:** Deep navy blue (primary), elegant gold (accent), warm white & light-blue tints (backgrounds), charcoal (body text)
- **Typography:** Playfair Display / DM Serif Display (headings) + Inter / DM Sans (body & UI)
- **Style:** Editorial, asymmetric, photography-first layouts with subtle micro-interactions
- **Fully responsive:** Desktop (1440px, 1280px), Tablet (1024px, 768px), Mobile (390px, 375px)

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom design system using CSS variables
- **JavaScript (Vanilla)** — Navigation behavior, accordions, gallery lightbox, scroll animations

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/suffa-education-school.git
   ```
2. Navigate to the project folder
   ```bash
   cd suffa-education-school
   ```
3. Open `index.html` in your browser, or run it with a local development server (e.g. VS Code Live Server) for the best experience.

No build tools or dependencies required — this is a pure HTML/CSS/JS project.
